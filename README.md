# ITk TC Temperature Analysis

Scripts for filtering and analyzing ITk module temperature data from thermal cycling (TC) measurements. The analysis includes NTC data validation, thermal cycle evaluation, glue thickness correlations, and test chuck comparisons.

## 1. Data Extraction — `data_filter.py`

`data_filter.py` searches a specified source directory for JSON measurement files, copies matching files to an isolation directory, validates the NTC temperature data, and combines the relevant measurement and glue thickness information.

### Configuration

The script uses **`config_filter.json`**.

* **`SOURCE_DIR` / `ISOLATION_DIR`** — Define where to search for measurement files and where to copy the matching files.
* **`KEYWORD`** — Keyword used to identify the relevant measurement files.
* **`GLUE_JSON`** — JSON file containing the average glue thickness for hybrids and powerboards (PBs).
* **`VALIDATION`** — Defines the NTC data validation criteria:

  * `ntc_array_length` — Required length of the NTC temperature array.
  * `min_temp` / `max_temp` — Allowed temperature range.

### Input Files

Raw measurement files should follow the expected naming convention, for example:

```text
SN20USEM20000083_20260423_1645_MODULE_IV_AMAC_TC.json
```

The glue thickness summary should be provided as a JSON array containing the component identifier and the corresponding glue thickness values.

Example:

```json
[
    {
        "component": "20USEM40000240",
        "L_avg_HYBRID_GLUE_THICKNESS_ABC": 126.9375,
        "R_avg_HYBRID_GLUE_THICKNESS_ABC": 402.75,
        "avg_HYBRID_GLUE_THICKNESS_ABC": null,
        "avg_PB_GLUE_THICKNESS": 153.3,
        "avg_PB_GLUE_THICKNESS_5": 128.0
    }
]
```

### Output

The script generates:

```text
filtered_summary.json
```

This consolidated file contains the relevant sensor metadata, thermal data, and glue thickness information required for the thermal cycling analysis.

---

## 2. Thermal Analysis — `TC_analysis.py`

`TC_analysis.py` processes the consolidated data generated by `data_filter.py`. It evaluates temperature stability, calculates thermal swings between cold and warm cycles, and investigates the relationship between thermal performance, glue thickness, and test chucks.

### Configuration

The script uses **`config_TC.json`**.

#### `FILTERING`

* **`trim_start` / `trim_end`** — Exclude startup and shutdown thermal deviations.
* **`min_seq_length`** — Exclude modules with insufficient or incomplete data.
* **`min_temp_swing`** — Exclude individual cycles with a ΔT below the specified threshold, e.g. incomplete cycles below 20 °C.

#### `CHUCKS`

Maps test chucks to their corresponding `daq_stream` and defines the marker shapes used in the plots.

### Output

The script generates a **`Thermal_analysis`** directory containing visualizations such as:

* Individual module thermal cycle plots
* Temperature difference (ΔT) summaries by chuck
* Glue thickness vs. temperature correlations
* Thermal swing difference distributions

## Usage

### 1. Prepare the input files

Ensure that the raw measurement files and glue thickness summary are available.

Example:

```text
SN20USEM20000083_20260423_1645_MODULE_IV_AMAC_TC.json
glue_thickness_summary.json
```

### 2. Configure the analysis

Update the configuration files to match the current dataset and test parameters:

```text
config_filter.json
config_TC.json
```

### 3. Run the data extraction

```bash
python data_filter.py
```

This generates:

```text
filtered_summary.json
```

### 4. Run the thermal cycling analysis

```bash
python TC_analysis.py
```

The resulting plots are saved in:

```text
Thermal_analysis/
```

## Workflow

```text
Raw measurement data
        ↓
data_filter.py
        ↓
filtered_summary.json
        ↓
TC_analysis.py
        ↓
Thermal_analysis/
```
